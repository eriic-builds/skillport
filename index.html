How to use Skillport

A small active toolkit.
A deep shelf behind it.

AI tools work best when they see only the skills relevant to the job. Skillport keeps everyday skills active and moves everything else to a shelf—available when needed, invisible when not.

01

Add a skill

$ skills new my-skill

Create it yourself, copy a skill into the library, or import one from GitHub.

02

Link your tools

$ skills link

Connect the active library to every supported AI client on your machine.

03

Check everything

$ skills doctor

Confirm skills, links, metadata, and Git state are healthy before you work.

▦ THE SHELF SYSTEM

Keep skills without loading them all.

A shelved skill stays safely stored in your library, but is disconnected from your AI clients. That keeps their skill lists short, reduces distraction, and helps the right skill win.

$ skills shelve universal-skill-probe$ skills unshelve commit-message$ skills shelf

The Skillport loop

One library. A focused path to every tool.

Skills live in one canonical home. Keep the useful few active, move the rest to the shelf, and link only that focused toolkit into your AI clients.
